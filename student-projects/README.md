# Day 6 student projects

Plain Vite + React (JavaScript), same shape as `npm create vite@latest`. These are standalone
copies of the main exercises. For live coding with no setup, use `../exercises/` instead. Each
project here runs on its own:

```bash
cd 01-live-input-starter
npm install
npm run dev
```

Vite's scaffold turns on StrictMode (`src/main.jsx`), and so do these. In development, effects
run setup, cleanup, setup on mount, so logs can appear twice. That's expected.
